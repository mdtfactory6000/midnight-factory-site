Midnight Factory — Privacy Policy

Last updated: October 13, 2026

1. About this application

Midnight Factory Community Assistant is a private tool operated by Midnight Factory to manage interactions on its own YouTube channel.

2. Information processed

The application may access publicly available YouTube comments, commenter display names, channel identifiers, comment identifiers and replies through the YouTube API.

3. How information is used

This information is used to identify comments requiring responses, generate relevant replies, prevent duplicate replies and flag comments for manual review.

4. Third-party services

The application uses Google YouTube API, Google Gemini, GitHub Actions and GitHub Issues. Selected comments requiring review may also be sent through Telegram.

5. Storage and security

Comment identifiers and processing records may be stored in a private GitHub repository. Access credentials are stored as encrypted GitHub Actions secrets.

6. Data retention and deletion

Processing records are retained for as long as needed to manage comments and prevent duplicate responses. They may be removed when no longer necessary.

7. YouTube API Services

By using this application, the channel operator authorizes access to YouTube API Services. Google's Privacy Policy is available at https://policies.google.com/privacy . Authorized access can be revoked through Google Account permissions .

8. Contact

For privacy questions or data deletion requests, please contact Midnight Factory through its official YouTube channel .
